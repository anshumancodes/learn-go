### methods in go
-  A **method is a function attached to a type**. It is defined using a **receiver**.
- Methods are functions associated with a type and are called using an instance of that type.
-  the reciver of a method can be of 2 types one is value type another is a pointer type.
- the pointer type change the value of orginally defined (class)/type .
- **Method value** → a method assigned to a variable, tied to a specific instance.
- **Pointer receiver** → method receives the address of the instance, allowing it to modify the original value.
- you have to make all the recivers  values or pointer , dont mix it up
