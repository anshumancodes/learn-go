### maps

- maps in go is a implementation of hashmaps or dictinoary.
- maps are used when we want to find things quickly, for other cases use struct.
-  if you intialise a map with var and you you assign a key to the map , you will get a error
- Go provides a construct to check whether a key is present in a map or not. It returns the value along with a boolean indicating whether the key exists.
-  you can loop over a map but not structs
- al the values in inside a struct dont have a memory location and u can point to it 

### anonymous functions

- An anonymous function is a function **without a name**. It can be defined and executed directly or assigned to a variable.
- You can also store it in a variable: and call it 


### closure

 - a closure is a function that references variables from outside its own function body
 -  the function may access and assign to the referenced variables
